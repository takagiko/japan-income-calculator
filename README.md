# 日本の給与所得 税・社会保険料 計算機

月給と賞与から、社会保険料・所得税・住民税・手取りを **計算式と根拠付き** で表示する Web 計算機。透明性を重視した設計で、各項目の値だけでなく「どの式で・どの法令やどの料率に基づいて算出されたか」が確認できます。

🔗 **公開サイト**: <https://japan-income-calculator.vercel.app/>

## 特徴

- **月給と夏冬ボーナスを別々に入力**し、それぞれに対する標準報酬月額・標準賞与額を正しく計算
- 各カードをクリックすると **「式・根拠」** が展開（所得税法の条文や協会けんぽ料率の参照を表示）
- 入力値は **URL のクエリパラメータに自動反映** され、リンクをそのまま共有可能
- 計算結果の **手取りを「年間 / 月給 / 夏ボ / 冬ボ」の 4 視点** で表示。各カードクリックで控除内訳（社保・所得税・住民税）も
- 各入力欄に **マウスを乗せるとツールチップ** で項目の意味を補足
- **浮動小数点誤差を排除**した精度（`utils/math.ts` の `rateFloor` / `rateMultiply` ヘルパーで整数演算化）

## 前提・固定条件（仕様爆発を避けるため）

- **年度**: 令和7年度（2025年4月〜2026年3月）
- **健康保険**: 協会けんぽ東京支部（健康保険料率 9.91% / 介護保険料率 1.59% / 厚生年金保険料率 18.300%）
- **雇用保険**: 一般の事業（労働者負担 5.5/1000）
- **住民税**: 東京都標準（市町村民税 6% + 道府県民税 4% + 均等割 + 森林環境税）
- **年齢**: 65歳未満（介護保険対象 40〜64歳はチェックボックスで選択）

## 計算範囲

### 含むもの

- 給与所得控除（速算表）
- 社会保険料（健保 / 介護 / 厚年 / 雇用、月給分と賞与分を別計算）
- 基礎控除（高所得段階減 2,400 万円超）
- 配偶者控除・配偶者特別控除（本人合計所得 900 万円超の段階減対応、配偶者所得 48〜133 万円の段階対応）
- 扶養控除（一般 / 特定 19-22 歳 / 老人 70 歳以上 / 同居老親 の 4 区分）
- 所得税（累進ブラケット + 復興特別所得税 2.1%）
- 住民税（所得割 + 均等割 + 調整控除）
- 手取り（年間・月給分・夏ボ分・冬ボ分の 4 視点）

### 既知の単純化（意図的なもの）

- 住民税は本来「前年所得に対する翌年度課税」だが、**同年度の年収に対して計算**する単純化
- 調整控除の人的控除差は法定値ではなく **「実際の控除額の差」を簡略適用**（配偶者特別控除の細部で多少のズレ）
- 雇用保険料は支払源（月給・夏ボ・冬ボ）で年収比按分して各源の手取り表示に反映
- 賞与の支給回数は年 0 回 / 1 回 / 2 回までを想定（年 3 回以上は合算で代用）

### スコープ外（実装していない）

- iDeCo（小規模企業共済等掛金控除）
- ふるさと納税（寄附金控除）
- 生命保険料控除、地震保険料控除
- 住宅ローン控除（税額控除）
- 医療費控除
- 障害者控除、寡婦・ひとり親控除、勤労学生控除

## 技術スタック

- **React 18.2** + TypeScript + **Vite 5**
- 状態管理: `useState` + 派生計算は `useMemo`（外部ライブラリなし）
- ルーティング: `URLSearchParams` + `window.history.replaceState`（react-router 不使用）
- スタイル: CSS（ESM import、CSS Modules 不使用）
- ホスティング: Vercel

ServiceNow Build Agent の生成アプリと同等のスタックで構成しており、UI Page 開発の経験を持ち込みやすい設計です。

## ディレクトリ構造

```
src/
├── client/
│   ├── main.tsx              # エントリポイント
│   ├── app.tsx               # ルートコンポーネント
│   ├── app.css               # 全体スタイル
│   ├── components/           # InputForm / CalcStep / DualCalcStep / Summary
│   ├── services/
│   │   ├── pipeline.ts       # 計算オーケストレータ
│   │   └── tax/              # 各種計算（純粋関数）
│   └── utils/
│       ├── types.ts          # CalcInput / CalcResult 等
│       ├── math.ts           # 浮動小数点誤差を避ける rateFloor / rateMultiply
│       └── urlState.ts       # URL ↔ 入力 の双方向変換
└── rules/                    # 料率テーブル・ブラケット定義
    ├── kyokai-kenpo-tokyo-2025.ts
    ├── employment-insurance-2025.ts
    ├── employment-income-deduction-2025.ts
    ├── basic-deduction-2025.ts
    ├── spouse-deduction-2025.ts
    ├── dependent-deduction-2025.ts
    ├── income-tax-brackets-2025.ts
    └── residence-tax-2025.ts
```

設計方針: 計算ロジック（`services/tax/`）と料率データ（`rules/`）を分離。年度更新は `rules/` の差し替えで完結する。

## ローカルで動かす

```sh
git clone https://github.com/takagiko/japan-income-calculator.git
cd japan-income-calculator
npm install
npm run dev
```

ブラウザで <http://localhost:5173/> を開く。

### スクリプト

| コマンド | 用途 |
|---|---|
| `npm run dev` | 開発サーバ（HMR 付き） |
| `npm run build` | 本番ビルド（`dist/` に出力） |
| `npm run preview` | 本番ビルドのローカル確認 |
| `npm run typecheck` | TypeScript 型チェックのみ |

## 免責

本ツールの計算結果は **概算** です。正式な税額・納付額の確定には、税務署または税理士等の専門家にご相談ください。
